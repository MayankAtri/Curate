# Stitch Enhanced Prompt: Curate Editorial Dashboard

## Intent
Generate a high-fidelity landing page and news feed for "Curate," an AI-powered news distillation platform.

## Aesthetic & Vibe
*   **Tone:** Editorial Brutalism. Minimalist, high-contrast, and focused on information density.
*   **Color Palette:** Use a warm newsprint off-white (#F4F0EB) for the background, deep ink-black (#111111) for all primary text and borders, and an aggressive electric vermilion (#FF3300) for primary call-to-action accents.
*   **Typography:** Set massive headlines in a characterful serif font (e.g., Fraunces style). Use a technical monospace (e.g., Chivo Mono) for all UI metadata, stats, and navigation labels.

## Structural Requirements
*   **Navigation:** Create a persistent top navigation bar with a massive wordmark logo "CURATE" on the left and technical navigation links (FEED, ANALYTICS, DISPATCH) on the right.
*   **Hero Section:** A bold hero header with the text "CUT THROUGH THE NOISE." using an outlined typography effect for the word "THROUGH."
*   **Bento Feed Layout:** A multi-column news feed grid. Each card should have:
    *   A 4px solid black border and zero border-radius.
    *   A harsh 8px solid black drop shadow.
    *   A grayscale hero image that shifts to full color on hover.
    *   Metadata labels (e.g., "3 MIN BRIEF", "98% MATCH") set in technical monospace.
*   **Metrics Bar:** Include a "System Status" or "Quick Stats" bar above the grid showing horizontal items like "TOTAL DISPATCHES: 1,240" and "MEAN READ RATIO: 84%".

## Iteration Instructions
*   Avoid all rounded corners or gradients.
*   Imagery should be high-contrast and editorial.
*   The search bar should resemble a command-line interface terminal input.
